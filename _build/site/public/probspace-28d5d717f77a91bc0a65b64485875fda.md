# Probability Space

## Random Experiment

- A _**random experiment**_ is an experiment in which the outcome varies in an unpredictable fashion when the experiment is repeated under the same conditions, i.e., *random*.
- An _**outcome**_ of a random experiment is a result that cannot be decomposed into other results.

## Sample Space

- The set of all possible outcomes for a random experiment is called the _**sample space**_ $\Omega$.

### Examples

1. Tossing a coin: $\Omega = \{H,T\}$
2. Tossing a coin twice: $\Omega = \{HH,HT,TH,TT\}$
3. Taking EEE 5544 and getting a grade:
   $
   \Omega = \{A,A-,B+,B,B-,C+,C,D,F\}
   $

4. Picking an integer at random:
   $
   \Omega = \{\ldots,-3,-2,-1,0,1,2,3,\ldots\}
   $

5. Checking the temperature (in $K$) at a random location:
   $
   \Omega = (0,\infty)
   $

- **Finite** $\Omega$: Examples 1, 2, and 3
- **Countably infinite** $\Omega$: Example 4
- **Discrete** $\Omega$: Examples 1–4
- **Continuous (uncountably infinite)** $\Omega$: Example 5

## Event Class

- An _**event**_ is a set of outcomes, i.e., a subset of $\Omega$,
  whose "likelihood" can be quantified.
- Two special events:
  - $\Omega =$ _**certain event**_
  - $\emptyset =$ _**impossible event**_
- An _**event class**_ $\mathcal{F}$ of a random experiment is a collection of events.

### Discrete Sample Space

For a discrete $\Omega$, we typically consider the event class
consisting of all subsets of $\Omega$, i.e.,
$
\mathcal{F} = 2^\Omega.
$
This is called the *power set* of $\Omega$.

#### Examples

1. Tossing a coin:

   $$
   \mathcal{F} = \{\emptyset,\{H\},\{T\},\{H,T\}\}.
   $$

2. Tossing a coin twice:

   $$
   \mathcal{F}
   =
   \left\{
   \emptyset,
   \{HH\},
   \{TT\},
   \{HT\},
   \{TH\},
   \{HH,TT\},
   \{HH,HT\},
   \ldots,
   \{HH,TT,HT\},
   \ldots,
   \{HH,TT,HT,TH\}
   \right\}.
   $$

3. If $\Omega=\{a_1,a_2,\ldots,a_N\}$, then

   $$
   \mathcal{F}
   =
   \left\{
   \emptyset,
   \{a_1\},
   \ldots,
   \{a_N\},
   \{a_1,a_2\},
   \ldots,
   \{a_1,a_2,a_3\},
   \ldots,
   \{a_1,a_2,\ldots,a_N\}
   \right\}.
   $$

   Altogether, there are $2^N$ events (why?).

4. For a countably infinite sample space

   $$
   \Omega=\{a_1,a_2,\ldots\},
   $$

   we can use the same idea as in the finite case, using the power set as the event space:

   $$
   \mathcal{F}
   =
   2^\Omega
   =
   \left\{
   \emptyset,
   \{a_1\},
   \ldots,
   \{a_N\},
   \{a_1,a_2\},
   \ldots,
   \{a_1,a_2,a_3\},
   \ldots,
   \{a_1,a_2,\ldots,a_n\},
   \ldots
   \right\}.
   $$

   This enumerates all subsets of $\Omega$. However, we need a better way to describe the power set.

### Continuous Sample Space

- For a continuous sample space, such as $\Omega=(0,\infty)$, there are uncountably infinitely many outcomes. Therefore, the enumeration method used in the finite case cannot be used to construct the event class.
- To discuss the solution, we first need to study set operations.

## Set Operations

- **Union:**

  $$
  A\cup B=\{x\in\Omega:x\in A\text{ or }x\in B\}.
  $$

- **Intersection:**

  $$
  A\cap B=\{x\in\Omega:x\in A\text{ and }x\in B\}.
  $$

- **Complement:**

  $$
  A^c=\{x\in\Omega:x\notin A\}.
  $$

- **Difference:**

  $$
  A\setminus B
  =
  \{x\in\Omega:x\in A\text{ and }x\notin B\}
  =
  A\cap B^c.
  $$

:::{prf:theorem} De Morgan's Laws

1. $(A\cup B)^c=A^c\cap B^c$.
2. $(A\cap B)^c=A^c\cup B^c$.
:::

:::{prf:proof}
We prove the first identity.

1. Since

   $$
   \begin{aligned}
   x\in(A\cup B)^c
   &\Rightarrow x\notin A\cup B \\
   &\Rightarrow x\notin A\text{ and }x\notin B \\
   &\Rightarrow x\in A^c\text{ and }x\in B^c \\
   &\Rightarrow x\in A^c\cap B^c,
   \end{aligned}
   $$

   we have

   $$
   (A\cup B)^c\subseteq A^c\cap B^c.
   $$

2. Conversely, since

   $$
   \begin{aligned}
   x\in A^c\cap B^c
   &\Rightarrow x\in A^c\text{ and }x\in B^c \\
   &\Rightarrow x\notin A\text{ and }x\notin B \\
   &\Rightarrow x\notin A\cup B \\
   &\Rightarrow x\in(A\cup B)^c,
   \end{aligned}
   $$

   we have

   $$
   A^c\cap B^c\subseteq(A\cup B)^c.
   $$

Combining the two inclusions gives

$$
(A\cup B)^c=A^c\cap B^c.
$$
:::

:::{prf:theorem}
Union and complement are enough to specify all other set operations.
:::

## Field (Algebra)

A **field (algebra)** is a collection of subsets of $\Omega$ that is closed under union and complement and contains both $\emptyset$ and $\Omega$. Thus, $\mathcal{F}$ is a field if it satisfies the following conditions:

- $\emptyset\in\mathcal{F}$ and $\Omega\in\mathcal{F}$.
- If $A\in\mathcal{F}$ and $B\in\mathcal{F}$, then $A\cup B\in\mathcal{F}$.
- If $A\in\mathcal{F}$, then $A^c\in\mathcal{F}$.

Operationally, a field contains all subsets of $\Omega$ that can be obtained by applying a finite number of set operations.

:::{prf:theorem}
For any finite $\Omega$, the power set $2^\Omega$ is a field.
:::

## $\sigma$-Field ($\sigma$-Algebra)

A field $\mathcal{F}$ is a **$\sigma$-field** if it satisfies the additional condition

$$
A_1,A_2,\ldots\in\mathcal{F}
\quad\Longrightarrow\quad
\bigcup_{i=1}^{\infty}A_i\in\mathcal{F}.
$$

Operationally, a $\sigma$-algebra contains all subsets of $\Omega$ that can be obtained through a countable number of set operations.

:::{prf:theorem}
For countably infinite $\Omega$, $2^\Omega$ is a $\sigma$-field.
:::

### Generating a $\sigma$-Field

- For a continuous (uncountably infinite) sample space $\Omega$, we often *generate* $\sigma$-fields from collections of subsets of $\Omega$.
- For a collection $\mathcal{A}$ of subsets of $\Omega$, consider the $\sigma$-field generated by $\mathcal{A}$: the smallest $\sigma$-field containing every subset that can be formed by performing countable set operations on members of $\mathcal{A}$.
- The $\sigma$-field generated by $\mathcal{A}$ is denoted by $\sigma(\mathcal{A})$.

## Event Class for a Continuous Sample Space

For a continuous (uncountably infinite) sample space $\Omega$, we consider event classes that are $\sigma$-fields on $\Omega$.

### Example: $\Omega=\mathbb{R}$

- Consider the collection $\mathcal{A}$ of all subsets of $\mathbb{R}$ of the form $(-\infty,a)$ for some $a\in\mathbb{R}$.
- The $\sigma$-field generated by $\mathcal{A}$ is called the *Borel $\sigma$-field*. It is commonly used as an event class for the sample space $\mathbb{R}$.
- The Borel $\sigma$-field contains essentially all events of practical interest.
- Although the *Borel sets* form a very rich class of subsets of $\mathbb{R}$, some subsets of $\mathbb{R}$ are not Borel sets. This is critically important for allowing the likelihoods of events to be quantified.

## Description of a Random Experiment

- The sample space $\Omega$ and an event class $\mathcal{F}$ can be used to describe a random experiment mathematically.
- We also need a way to quantify the likelihood of events. This is done by a mapping called a *probability measure* $P$, which will be discussed in the next section.
- In summary, the mathematical object describing a random experiment is the triple

  $$
  (\Omega,\mathcal{F},P),
  $$

  called the **probability space** of the random experiment.+
