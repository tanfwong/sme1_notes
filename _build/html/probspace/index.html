Probability Space

Random Experiment¶

  • A random experiment is an experiment in which the outcome varies in an unpredictable fashion when the experiment is repeated under the same conditions, i.e., random.

  • An outcome of a random experiment is a result that cannot be decomposed into other results.

Sample Space¶

  • The set of all possible outcomes for a random experiment is called the sample space Ω\OmegaΩ.

Example 1

  1. Tossing a coin: Ω={H,T}\Omega = \{H,T\}Ω={H,T}

  2. Tossing a coin twice: Ω={HH,HT,TH,TT}\Omega = \{HH,HT,TH,TT\}Ω={HH,HT,TH,TT}

  3. Taking EEE 5544 and getting a grade: Ω={A,A−,B+,B,B−,C+,C,D,F} \Omega = \{A,A-,B+,B,B-,C+,C,D,F\}Ω={A,A−,B+,B,B−,C+,C,D,F}

  4. Picking an integer at random: Ω={…,−3,−2,−1,0,1,2,3,…} \Omega = \{\ldots,-3,-2,-1,0,1,2,3,\ldots\}Ω={…,−3,−2,−1,0,1,2,3,…}

  5. Checking the temperature (in KKK) at a random location: Ω=(0,∞) \Omega = (0,\infty)Ω=(0,∞)

  • Finite Ω\OmegaΩ: Examples 1, 2, and 3

  • Countably infinite Ω\OmegaΩ: Example 4

  • Discrete Ω\OmegaΩ: Examples 1–4

  • Continuous (uncountably infinite) Ω\OmegaΩ: Example 5

Event Class¶

  • An event is a set of outcomes, i.e., a subset of Ω\OmegaΩ, whose “likelihood” can be quantified.

  • Two special events:

    • Ω=\Omega =Ω= certain event

    • ∅=\emptyset =∅= impossible event

  • An event class F\mathcal{F}F of a random experiment is a collection of events.

Discrete Sample Space¶

For a discrete Ω\OmegaΩ, we typically consider the event class consisting of all subsets of Ω\OmegaΩ, i.e., F=2Ω. \mathcal{F} = 2^\Omega.F=2Ω. This is called the power set of Ω\OmegaΩ.

Example 2

  1. Tossing a coin: F={∅,{H},{T},{H,T}}. \mathcal{F} = \{\emptyset,\{H\},\{T\},\{H,T\}\}.F={∅,{H},{T},{H,T}}.

  2. Tossing a coin twice:

F={∅,{HH},{TT},{HT},{TH},{HH,TT},{HH,HT},…,{HH,TT,HT},…,{HH,TT,HT,TH}}.\mathcal{F} = \left\{ \emptyset, \{HH\}, \{TT\}, \{HT\}, \{TH\}, \{HH,TT\}, \{HH,HT\}, \ldots, \{HH,TT,HT\}, \ldots, \{HH,TT,HT,TH\} \right\}.F={∅,{HH},{TT},{HT},{TH},{HH,TT},{HH,HT},…,{HH,TT,HT},…,{HH,TT,HT,TH}}.

    F={∅,{a1},…,{aN},{a1,a2},…,{a1,a2,a3},…,{a1,a2,…,aN}}.\mathcal{F} = \left\{ \emptyset, \{a_1\}, \ldots, \{a_N\}, \{a_1,a_2\}, \ldots, \{a_1,a_2,a_3\}, \ldots, \{a_1,a_2,\ldots,a_N\} \right\}.F={∅,{a1​},…,{aN​},{a1​,a2​},…,{a1​,a2​,a3​},…,{a1​,a2​,…,aN​}}.

  2. For a countably infinite sample space Ω={a1,a2,…}, \Omega=\{a_1,a_2,\ldots\},Ω={a1​,a2​,…}, we can use the same idea as in the finite case, using the power set as the event space:

    F=2Ω={∅,{a1},…,{aN},{a1,a2},…,{a1,a2,a3},…,{a1,a2,…,an},…}.\mathcal{F} = 2^\Omega = \left\{ \emptyset, \{a_1\}, \ldots, \{a_N\}, \{a_1,a_2\}, \ldots, \{a_1,a_2,a_3\}, \ldots, \{a_1,a_2,\ldots,a_n\}, \ldots \right\}.F=2Ω={∅,{a1​},…,{aN​},{a1​,a2​},…,{a1​,a2​,a3​},…,{a1​,a2​,…,an​},…}.

Continuous Sample Space¶

  • For a continuous sample space, such as Ω=(0,∞)\Omega=(0,\infty)Ω=(0,∞), there are uncountably infinitely many outcomes. Therefore, the enumeration method used in the finite case cannot be used to construct the event class.

  • To discuss the solution, we first need to study set operations.

Set Operations¶

  • Union: A∪B={x∈Ω:x∈A or x∈B}A\cup B=\{x\in\Omega:x\in A\text{ or }x\in B\}A∪B={x∈Ω:x∈A or x∈B}

  • Intersection: A∩B={x∈Ω:x∈A and x∈B}A\cap B=\{x\in\Omega:x\in A\text{ and }x\in B\}A∩B={x∈Ω:x∈A and x∈B}

  • Complement: Ac={x∈Ω:x∉A}A^c=\{x\in\Omega:x\notin A\}Ac={x∈Ω:x∈/A}

  • Difference: A∖B={x∈Ω:x∈A and x∉B}=A∩BcA \setminus B = \{x\in\Omega:x\in A \text{ and } x\notin B\} = A\cap B^cA∖B={x∈Ω:x∈A and x∈/B}=A∩Bc

Remark 1 (De Morgan’s Laws)

  1. (A∪B)c=Ac∩Bc(A\cup B)^c=A^c\cap B^c(A∪B)c=Ac∩Bc.

  2. (A∩B)c=Ac∪Bc(A\cap B)^c=A^c\cup B^c(A∩B)c=Ac∪Bc.

Proof

We prove the first identity as an example.

Since

x∈(A∪B)c⇒x∉A∪B⇒x∉A and x∉B⇒x∈Ac and x∈Bc⇒x∈Ac∩Bc,\begin{align*} x\in(A\cup B)^c &\Rightarrow x\notin A\cup B \\ &\Rightarrow x\notin A\text{ and }x\notin B \\ &\Rightarrow x\in A^c\text{ and }x\in B^c \\ &\Rightarrow x\in A^c\cap B^c, \end{align*}x∈(A∪B)c​⇒x∈/A∪B⇒x∈/A and x∈/B⇒x∈Ac and x∈Bc⇒x∈Ac∩Bc,​

we have (A∪B)c⊆Ac∩Bc(A\cup B)^c\subseteq A^c\cap B^c(A∪B)c⊆Ac∩Bc.

Conversely, since

x∈Ac∩Bc⇒x∈Ac and x∈Bc⇒x∉A and x∉B⇒x∉A∪B⇒x∈(A∪B)c,\begin{align*} x\in A^c\cap B^c &\Rightarrow x\in A^c\text{ and }x\in B^c \\ &\Rightarrow x\notin A\text{ and }x\notin B \\ &\Rightarrow x\notin A\cup B \\ &\Rightarrow x\in(A\cup B)^c, \end{align*}x∈Ac∩Bc​⇒x∈Ac and x∈Bc⇒x∈/A and x∈/B⇒x∈/A∪B⇒x∈(A∪B)c,​

we have Ac∩Bc⊆(A∪B)cA^c\cap B^c\subseteq(A\cup B)^cAc∩Bc⊆(A∪B)c.

Combining the two inclusions gives (A∪B)c=Ac∩Bc(A\cup B)^c=A^c\cap B^c(A∪B)c=Ac∩Bc.

Remark 2

Union and complement are enough to specify all other set operations.

Field (Algebra)¶

  • A field (algebra) is a collection of subsets of Ω\OmegaΩ that is closed under union and complement and contains both ∅\emptyset∅ and Ω\OmegaΩ. Thus, F\mathcal{F}F is a field if it satisfies the following conditions:

    1. ∅∈F\emptyset\in\mathcal{F}∅∈F and Ω∈F\Omega\in\mathcal{F}Ω∈F.

    2. If A∈FA\in\mathcal{F}A∈F and B∈FB\in\mathcal{F}B∈F, then A∪B∈FA\cup B\in\mathcal{F}A∪B∈F.

    3. If A∈FA\in\mathcal{F}A∈F, then Ac∈FA^c\in\mathcal{F}Ac∈F.

  • Operationally, a field contains all subsets of Ω\OmegaΩ that can be obtained by applying a finite number of set operations.

Remark 3

For any finite Ω\OmegaΩ, the power set 2Ω2^\Omega2Ω is a field.

σ\sigmaσ-Field (σ\sigmaσ-Algebra)¶

  • A field F\mathcal{F}F is a σ\sigmaσ-field if it satisfies the additional condition

    1. If A1,A2,…∈FA_1,A_2,\ldots\in\mathcal{F}A1​,A2​,…∈F, then ⋃i=1∞Ai∈F\bigcup_{i=1}^{\infty}A_i\in\mathcal{F}⋃i=1∞​Ai​∈F.

  • Operationally, a σ\sigmaσ-algebra contains all subsets of Ω\OmegaΩ that can be obtained through a countable number of set operations.

Remark 4

For countably infinite Ω\OmegaΩ, 2Ω2^\Omega2Ω is a σ\sigmaσ-field.

Generating a σ\sigmaσ-Field¶

  • For a continuous (uncountably infinite) sample space Ω\OmegaΩ, we often generate σ\sigmaσ-fields from collections of subsets of Ω\OmegaΩ.

  • For a collection A\mathcal{A}A of subsets of Ω\OmegaΩ, consider the σ\sigmaσ-field generated by A\mathcal{A}A: the smallest σ\sigmaσ-field containing every subset that can be formed by performing countable set operations on members of A\mathcal{A}A.

  • The σ\sigmaσ-field generated by A\mathcal{A}A is denoted by σ(A)\sigma(\mathcal{A})σ(A).

Event Class for a Continuous Sample Space¶

  • For a continuous (uncountably infinite) sample space Ω\OmegaΩ, we consider event classes that are σ\sigmaσ-fields on Ω\OmegaΩ.

Example 3 (Event class for Ω=R\Omega=\mathbb{R}Ω=R)

  • Consider the collection A\mathcal{A}A of all subsets of R\mathbb{R}R of the form (−∞,a)(-\infty,a)(−∞,a) for some a∈Ra\in\mathbb{R}a∈R.

  • The σ\sigmaσ-field generated by A\mathcal{A}A is called the Borel σ\sigmaσ-field. It is commonly used as an event class for the sample space R\mathbb{R}R.

  • The Borel σ\sigmaσ-field contains essentially all events of practical interest.

  • Although the Borel sets form a very rich class of subsets of R\mathbb{R}R, some subsets of R\mathbb{R}R are not Borel sets. This is critically important for allowing the likelihoods of events to be quantified.

Description of a Random Experiment¶

  • The sample space Ω\OmegaΩ and an event class F\mathcal{F}F can be used to describe a random experiment mathematically.

  • We also need a way to quantify the likelihood of events. This is done by a mapping called a probability measure PPP, which will be discussed in the next section.

  • In summary, the mathematical object describing a random experiment is the triple (Ω,F,P)(\Omega,\mathcal{F},P)(Ω,F,P), called the probability space of the random experiment.
